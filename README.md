# KH Construction — GA4 & GTM Marketing Analytics

## Project Overview

A hands-on marketing analytics project for KH Construction, a small construction business.

The goal was to implement website tracking and measure important visitor actions that could indicate potential enquiries.

## Business Problem

The website did not have reliable measurement of visitor interactions such as WhatsApp, phone, and email clicks.

This made it difficult to understand how visitors were engaging with the website.

## What I Implemented

- Google Analytics 4 (GA4) setup
- Google Tag Manager (GTM) implementation
- WhatsApp click tracking
- Phone click tracking
- Email click tracking
- Key-event measurement
- Event validation using GA4 DebugView
- Traffic and engagement analysis
- Looker Studio dashboard

## Tools Used

- Google Analytics 4
- Google Tag Manager
- Looker Studio

## Key Outcome

The implementation created a basic measurement framework for understanding website engagement and contact actions.

This allows the business to move from simply having website traffic to measuring meaningful user interactions.
